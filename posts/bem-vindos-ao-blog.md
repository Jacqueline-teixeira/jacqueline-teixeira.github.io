Este é o primeiro post deste blog. A ideia aqui é simples: ter um espaço
livre para escrever sobre o que vier à cabeça, sem compromisso com um tema
fixo — pode ser tecnologia, experiências pessoais, livros, ideias soltas ou
qualquer outra coisa que fizer sentido no momento.

## Como esse blog funciona

Cada post é um arquivo Markdown simples na pasta `posts/`, listado no arquivo
`posts/posts.json`. Não existe backend, banco de dados ou build: tudo é lido
diretamente pelo navegador.

Para escrever um novo post:

1. Crie um arquivo `posts/seu-slug.md` com o texto em Markdown.
2. Adicione uma entrada correspondente em `posts/posts.json` com `slug`,
   `title`, `date`, `excerpt` e `tags`.
3. Faça commit e push — o GitHub Pages atualiza o site automaticamente.

> Markdown suporta títulos, listas, **negrito**, *itálico*, links, citações e
> blocos de código, então dá para escrever com liberdade de formatação.

Seja bem-vindo(a) a este espaço.
